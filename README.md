## 📌 프로젝트 소개

강원도 산불 이재민이 **시기별로 무엇을 해야 하는지**, **어떤 지원을 받을 수 있는지** 한눈에 알 수 있도록 만든 웹사이트입니다.
이재민 중 고령자가 많다는 점을 고려해 **큰 글씨, 쉬운 말, 단순한 메뉴**로 만들었습니다.

또한 이재민을 돕고 싶은 분들을 위해 **봉사, 피해목 업사이클링, 피해 결연 농가**를 한곳에 모아
강원대학교와 지역이 함께 회복하는 방법을 제안합니다.

## 🧭 화면 구성

첫 화면에서 두 갈래로 나뉩니다.

| 🏠 산불 이재민이신가요? | 🤲 따뜻한 손길 내밀기 |
|---|---|
| 할 일 확인 (시기별 체크리스트) | 봉사 신청 (학부생 학점연계과목) |
| 나에게 맞는 지원 찾기 (질문 4개) | 피해목 업사이클링 (강원대 비교과 · 지역 기업체 협력) |
| 분야별 지원 제도 (생활안정·주거·농업·소상공인·세금) | 피해 결연 농가 (강원대학교가 도와드립니다) |
| 마음 회복 (트라우마 증상, 상담 기관) | |
| 지원 창구 (담당 정부 부처 번호) | |
| 자주 묻는 질문 | |

## ✨ 주요 기능

- **시기별 회복 체크리스트**: 직후~1주 / 1개월 / 6개월 / 1년 이후. 체크한 내용은 브라우저에 저장됩니다.
- **나에게 맞는 지원 찾기**: 예/아니요로 답하면 해당되는 지원만 보여 주고, 결과를 인쇄할 수 있습니다.
- **고령자 배려**: 글씨 크기 3단계(작게·보통·크게), 인쇄용 화면, 휴대폰 하단 메뉴
- **정보 출처 표시**: 모든 지원 정보에 출처를 적었습니다.
- 모든 페이지 하단에 "정확한 내용은 관할 시·군청에 확인하세요" 안내

## 🤝 피해목 업사이클링

산불에 탄 나무로 굿즈와 생활 소품을 만드는 **강원대학교 비교과 프로그램**입니다.

1. 피해목 모으기
2. 지역 목공 기업과 학생이 함께 만들기 (**지역 기업체 협력**)
3. 강원대학교 캠퍼스에서 판매
4. 판매 수익금을 산불 이재민에게 기부

신청: [강원대학교 HIGH (비교과 통합관리시스템)](https://high.kangwon.ac.kr/)

## 📂 폴더 구조

```
├── index.html      첫 화면 (슬로건 + 두 갈래 선택)
├── home.html       이재민 안내: 시기별 회복 체크리스트
├── find.html       나에게 맞는 지원 찾기
├── support.html    분야별 지원 제도
├── mind.html       마음 회복
├── contact.html    지원 창구 안내
├── faq.html        자주 묻는 질문
├── together.html   따뜻한 손길 내밀기 (봉사 · 피해목 업사이클링 · 결연 농가)
├── css/            디자인 (style.css), 인쇄용 화면 (print.css)
├── js/             동작 (메뉴, 글씨 크기, 체크리스트, 지원 찾기)
├── data/           ★ 사이트 내용 (지원 제도, 체크리스트, 상담 기관, FAQ)
└── img/            로고
```

## ✏️ 내용 고치는 방법

코드를 몰라도 `data` 폴더의 파일만 고치면 사이트 전체에 반영됩니다.

| 파일 | 내용 |
|---|---|
| `data/checklist.js` | 시기별 할 일 |
| `data/support.js` | 분야별 지원 제도 (대상, 신청 장소, 필요 서류, 문의 전화, 출처) |
| `data/finder.js` | '지원 찾기' 질문 |
| `data/mind.js` | 마음 회복 증상, 상담 기관 |
| `data/contacts.js` | 지원 창구 |
| `data/faq.js` | 자주 묻는 질문 |

- 따옴표 `"` 안의 글자만 고치고, 쉼표 `,`와 괄호 `{ } [ ]`는 지우지 마세요.
- 전화번호는 공식 기관 누리집에서 확인한 번호만 넣어 주세요.

## 💻 실행 방법

설치할 것은 없습니다. `index.html`을 더블클릭하면 브라우저에서 열립니다.
